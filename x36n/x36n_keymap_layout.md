```

│ F7    │ F8    │ F9    │ F10   │ F11   │ F12   │ │ PG↓   │ ←     │ ↓     │ →     │ LS(←) │ LS(→) │

```

**特殊功能说明：**
| 按键 | 功能 | 代码 |
|------|------|------|
| BT₀/BT₁/BT₂ | 切换蓝牙配置文件 0/1/2 | `&bt BT_SEL 0/1/2` |
| BT_CLR | 清除当前蓝牙配对 | `&bt BT_CLR` |
| USB/BLE | 切换输出模式 | `&out OUT_USB/OUT_BLE` |
| ▶/⏸ | 播放/暂停 | `&kp C_PP` |
| MUTE | 静音 | `&kp C_MUTE` |
| VOL-/VOL+ | 音量减/增 | `&kp C_VOL_DN/C_VOL_UP` |
| PREV/NEXT | 上一曲/下一曲 | `&kp C_PREV/C_NEXT` |
| LG(SP) | Left GUI + Space | `&kp LG(SPACE)` |
| TO 0 | 切换回第 0 层 | `&to 0` |

**特殊功能说明：**
| 按键 | 功能 | 代码 | 位置 |
|------|------|------|------|
| BOOT | 进入 bootloader 模式 | `&bootloader` | 第 4 行第 7 列 (左侧最后一个) |

## 💡 宏定义说明

### xtips 宏
```c
xtips: xtips {
    compatible = "zmk,behavior-macro";
    label = "XTIPS";
    #binding-cells = <0>;
    bindings = <&kp LS(X) &kp KP_DOT &kp LS(T) &kp I &kp P &kp S>;
    wait-ms = <1>;
    tap-ms = <1>;
};
```
**功能：** 自动输入 `.tips` (LS(X)=x, KP_DOT=., LS(T)=T, I=i, P=p, S=s)
