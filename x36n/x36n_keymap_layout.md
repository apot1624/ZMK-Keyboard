## 📌 第 2 层 - FN2 功能/媒体层 (fn2_layer)
*通过按住右下角 `SPACE` 触发 (`&lt 2 SPACE`)*

| 行\列 | C1 | C2 | C3 | C4 | C5 | C6 | C7 | C8 | C9 | C10 | C11 | C12 |
|-------|----|----|----|----|----|----|----|----|----|-----|-----|------|
| **R1** | F1 | F2 | F3 | F4 | F5 | F6 | PG_UP | HOME | ↑ | END | LS(↑) | LS(↓) |
| **R2** | F7 | F8 | F9 | F10 | F11 | F12 | PG_DN | ← | ↓ | → | LS(←) | LS(→) |
| **R3** | BT₀ | BT₁ | BT₂ | BT_CLR | USB | BLE | ▶/⏸ | MUTE | VOL- | VOL+ | PREV | NEXT |
| **R4** | - | - | - | LCTRL | LG(SPACE) | LSHFT | LALT | **TO 0** | LWIN | - | - | - |

### FN2 层特殊功能说明：
| 按键 | 功能描述 | 代码 |
|------|----------|------|
| BT₀ | 切换蓝牙配置文件 0 | `&bt BT_SEL 0` |
| BT₁ | 切换蓝牙配置文件 1 | `&bt BT_SEL 1` |
| BT₂ | 切换蓝牙配置文件 2 | `&bt BT_SEL 2` |
| BT_CLR | 清除当前蓝牙配对 | `&bt BT_CLR` |
| USB | 切换输出模式为 USB | `&out OUT_USB` |
| BLE | 切换输出模式为蓝牙 | `&out OUT_BLE` |
| ▶/⏸ | 播放/暂停 | `&kp C_PP` |
| MUTE | 静音 | `&kp C_MUTE` |
| VOL- | 音量减 | `&kp C_VOL_DN` |
| VOL+ | 音量增 | `&kp C_VOL_UP` |
| PREV | 上一曲 | `&kp C_PREV` |
| NEXT | 下一曲 | `&kp C_NEXT` |
| LG(SPACE) | Left GUI + Space (命令+空格) | `&kp LG(SPACE)` |

## 🔑 图例说明

| 符号 | 含义 | 代码示例 |
|------|------|----------|
| `[FN1]` | 按住切换到第 1 层 | `&lt 1 SPACE` |
| `[FN2]` | 按住切换到第 2 层 | `&lt 2 SPACE` |
| `TO 0` | 切换到第 0 层 (默认层) | `&to 0` |
| `MO(4)` | 按住切换到第 4 层 | `&mo(4)` |
| `LG(SPACE)` | Left GUI + Space | `&kp LG(SPACE)` |
| `LS(X)` | Left Shift + X | `&kp LS(UP)` |
| `BT₀/BT₁/BT₂` | 蓝牙配置 0/1/2 | `&bt BT_SEL 0` |
| `-` | 无按键 | `&none` |

## 🎯 宏定义 (macros)

### xtips 宏
```dts
xtips: xtips {
    compatible = "zmk,behavior-macro";
    label = "XTIPS";
    bindings = <&kp LS(X) &kp KP_DOT &kp LS(T) &kp I &kp P &kp S>;
    wait-ms = <1>;
    tap-ms = <1>;
};
```
**功能**: 自动输入 `.tips` (依次输入：大写 X → 点 → 大写 T → I → P → S)
